# LottieX и nginx на локальном HTTP

Замер выполнен 18 ноября 2026 на Intel Core i5-11400H с 12 логическими процессорами и Linux 7.3.4. Сравнивались release-сборка LottieX 0.1.0 с GCC 16.2.1 и nginx 1.28.0 из официальных исходников, собранный с `--without-http_rewrite_module --without-http_gzip_module`. Для обоих использовались 8 workers, новое HTTP-соединение на каждый запрос и журнал запросов с выводом в `/dev/null`. nginx раздавал статику через `sendfile`. Оба прокси передавали ответы без полного буфера и использовали один FastAPI 0.163.2 с Uvicorn 0.54.0.

Каждый вариант прогрет и измерен три раза по 1000 запросов на клиента. В таблице приведены медианы RPS, p95 и PSS по прогонам. PSS — пропорциональный объём памяти процесса и его дочерних процессов. Во всех прогонах каждый запрос получил ожидаемый ответ.

| Нагрузка | Клиенты | LottieX, req/s | nginx, req/s | p95 LottieX / nginx, мс | PSS LottieX / nginx, КиБ |
| :--- | ---: | ---: | ---: | ---: | ---: |
| Статика, 16 КиБ | 1 | 6 380 | 7 896 | 0,200 / 0,153 | 1 542 / 3 113 |
| Статика, 16 КиБ | 8 | 29 296 | 34 215 | 0,325 / 0,290 | 1 541 / 3 106 |
| Прокси FastAPI, JSON 34 байта | 1 | 1 893 | 2 145 | 0,726 / 0,639 | 1 569 / 3 173 |
| Прокси FastAPI, JSON 34 байта | 8 | 3 293 | 3 368 | 2,983 / 2,917 | 1 569 / 3 684 |

В этом тесте nginx обслуживал больше запросов в секунду. При 8 клиентах разница на прокси составила около 2%, а LottieX использовал примерно 43% памяти nginx. Замер показывает производительность на коротких локальных ответах. При длительных SSR или SSE один worker LottieX занят на весь поток.

## Как повторить

Поднимите локальный FastAPI с фиксированным ответом `GET /bench`. Например, сохраните следующий код в `bench_api.py` и запустите `uvicorn bench_api:app --host 127.0.0.1 --port 8000 --no-access-log`.

```python
from fastapi import FastAPI

app = FastAPI()


@app.get("/bench")
async def bench():
    return {"service": "fastapi", "ready": True}
```

Скрипт запускает LottieX и nginx на свободных локальных портах и выводит результаты каждого прогона в JSON Lines.

```bash
make release
python3 tests/benchmark.py --nginx /path/to/nginx --backend http://127.0.0.1:8000 --requests 1000
```
